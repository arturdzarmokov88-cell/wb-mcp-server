# Коннектор Claude ↔ кабинет Wildberries

Небольшой сервер, через который Claude работает с вашим кабинетом WB.
Он работает на арендованном VPS в облаке, круглосуточно, независимо от вашего компьютера.
API-ключ WB хранится только на сервере, в Claude он не вводится.

**Что умеет**

| Чтение | Запись (выключена по умолчанию) |
|---|---|
| Заказы, продажи и возвраты | Ответы на отзывы |
| Остатки на складах WB | Ответы на вопросы |
| Финансовый отчёт о реализации | Изменение цен и скидок |
| Цены, карточки товаров | Рекламные ставки |
| Отзывы и вопросы покупателей | Запуск и пауза кампаний |
| Реклама: кампании, статистика, поисковые фразы, бюджеты | Минус-фразы |

Каждое изменение идёт в два шага: сервер показывает «было → станет» и выдаёт
подписанный код (действует 10 минут), и только с этим кодом изменение применяется.
Цена не может измениться больше чем на `MAX_PRICE_CHANGE_PCT` процентов за раз,
скидка не может превысить `MAX_DISCOUNT_PCT`. Все изменения пишутся в журнал.

## Шаг 1. Токен в кабинете WB

1. Кабинет продавца → **Настройки → Доступ к API** → **Создать токен**.
2. Разделы: **Статистика, Аналитика, Контент, Цены и скидки, Вопросы и отзывы, Продвижение, Финансы**.
3. Галочка **«Только на чтение»** — если Claude должен только смотреть. Если нужны изменения
   (с вашим подтверждением), создайте токен без этой галочки.
4. Сохраните токен у себя: WB покажет его один раз. Действует 180 дней.

Никому не присылайте токен, в том числе в чат с Claude.

## Шаг 2. Арендуйте VPS

Подойдёт самый дешёвый тариф у любого провайдера:

- **ОС:** Ubuntu 22.04 или 24.04
- **Ресурсы:** 1 ядро, 1 ГБ памяти, 10+ ГБ диска
- **Обязательно:** публичный IPv4-адрес

После создания провайдер покажет **IP-адрес** и **пароль root** (или пришлёт их на почту).

## Шаг 3. Загрузите код на GitHub

1. Зарегистрируйтесь на github.com и создайте новый репозиторий, например `wb-mcp-server`,
   тип **Public**. В коде нет секретов: токен и секретная строка хранятся только на сервере.
2. **Add file → Upload files** и перетащите все файлы из этой папки
   (`server.py`, `Dockerfile`, `docker-compose.yml`, `Caddyfile`, `install.sh`,
   `requirements.txt`, `.gitignore`, `.env.example`, `README.md`).
3. Нажмите **Commit changes**.

## Шаг 4. Установите сервер

1. Откройте на компьютере терминал:
   - **Windows:** меню Пуск → «PowerShell»;
   - **Mac:** программа «Терминал».
2. Подключитесь к серверу (вместо `1.2.3.4` ваш IP):
   ```
   ssh root@1.2.3.4
   ```
   На вопрос `Are you sure you want to continue connecting` ответьте `yes`, затем введите пароль
   (при вводе он не отображается — это нормально).
3. Выполните по очереди (вместо `ВАШ_ЛОГИН` ваш логин на GitHub):
   ```
   apt-get update && apt-get install -y git
   git clone https://github.com/ВАШ_ЛОГИН/wb-mcp-server.git
   cd wb-mcp-server
   bash install.sh
   ```
4. Скрипт попросит вставить токен WB (вставьте правой кнопкой мыши и нажмите Enter).
   Через несколько минут он напечатает **адрес коннектора** вида:
   ```
   https://1-2-3-4.sslip.io/СЕКРЕТНАЯ_СТРОКА/mcp
   ```
   Сохраните его. Это секрет: кто его знает, тот получает доступ к серверу.

## Шаг 5. Подключите к Claude

В Claude откройте настройки → **Коннекторы** → **добавить пользовательский коннектор**,
вставьте адрес и сохраните. В новом чате напишите «Проверь подключение к WB».

## Полезные команды на сервере

Все команды выполняются в папке `wb-mcp-server` (`cd ~/wb-mcp-server`).

| Задача | Команда |
|---|---|
| Посмотреть журнал | `docker compose logs --tail 100 wb-mcp` |
| Перезапустить | `docker compose restart` |
| Снова показать адрес коннектора | `bash install.sh` |

**Обновить программу, заменить токен, включить изменения или сменить секретный адрес** —
всё делается одним скриптом:
```
cd ~/wb-mcp-server
git fetch -q && git reset -q --hard origin/main && bash update.sh
```
Скрипт по очереди спросит новый токен (Enter — оставить прежний), включать ли изменения
и менять ли секретный адрес, затем перезапустит сервер и покажет адрес коннектора.

**Токен WB истекает через 180 дней.** Создайте новый и запустите `bash update.sh`.
